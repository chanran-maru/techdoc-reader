기본적으로 키는 브라우저 세션 동안만 유지됩니다. 브라우저 재시작·확장 다시 로드 시 다시 입력하세요.
선택하면 키가 로컬에 저장됩니다. 브라우저 프로필에 접근 가능한 사람으로부터 키를 보호하는 암호화 저장소는 아닙니다. 키를 비우고 저장하면 삭제됩니다.
번역 버튼을 누른 선택 텍스트(최대 1,000자)가 위 AI 제공자에게 전송되며 비용이 발생할 수 있습니다.
AI 설명 버튼을 누르면 선택 텍스트와 주변 문맥(최대 600자)이 위 AI 제공자에게 전송됩니다. 민감한 문서에서는 허용을 해제하세요.
동작 방식
• 확장 팝업의 '이 페이지에서 사용'을 누른 페이지에서만 실행합니다.
• 번역: Chrome 내장 번역 API를 먼저 사용합니다. 외부 번역은 위에서 허용한 경우에만 대체합니다.
• AI 설명: 위에서 외부 전송을 허용한 경우 API 키를 사용합니다.
